주요 데이터 흐름 (화살표 요약)

  1. User Chat: User → Frontend → Daphne → Django → LangChain ↔ OpenAI API → Django → WebSocket → User
  2. Vector Search: LangChain ↔ PostgreSQL (pgvector) — 양방향
  3. WebSocket Channel Layer: Daphne ↔ Redis ※ 원본에서 방향 잘못
  4. Async Jobs: Django → Redis (broker) → Celery Worker → PostgreSQL
  5. TTS: LangChain/Django → Runpod GPU (SoVITS) → 음성 파일 반환 ※ 요청 화살표 추가
  6. Image Gen: Content Pipeline → Runpod GPU (Z-image-turbo) → 이미지
  7. Content Pipeline: n8n → Playwright / HeyGen → PostgreSQL(generated_contents) → SNS
  8. Data Ingest: 하리 페르소나.docx → ingest_to_pgvector.py → PostgreSQL
  9. Auth: Frontend → Google / NAVER OAuth → Django (allauth)
  10. Deploy: GitHub → GitHub Actions → AWS EB
  11. Admin: 관리자 → 관리자 페이지 → Daphne → Django Admin
